MONO 회원별 독립 장바구니

변경: 장바구니 항목을 PostgreSQL member_cart_items 테이블에 user_id별로 저장합니다.
- 로그인 회원별로 독립된 장바구니
- 다른 기기에서 같은 계정으로 로그인해도 같은 장바구니 조회
- 다른 계정 로그인 시 이전 계정 장바구니 보이지 않음
- 수량 변경/삭제/주문 성공 시 현재 회원의 데이터만 수정
- 서버에서 상품/옵션 가격 및 품절 여부 재검증
- 기존 브라우저 세션 mono_cart 데이터는 이전하지 않습니다.

배포: app.py를 기존 프로젝트에 덮어쓰고 git push.
DB 초기화 과정에서 member_cart_items 테이블이 자동 생성됩니다.
실제 DB 연결 및 주문 동작은 배포 환경에서 테스트해야 합니다.
