MONO 카테고리 검색 및 정렬 추가

파일 교체:
  app.py -> 프로젝트 루트/app.py
  templates/category.html -> 프로젝트/templates/category.html

중요: app.py는 이전 'MONO_상품검색_추가.zip'의 app.py를 기반으로 제작했습니다.
      그 후 app.py에 별도 변경이 있었다면 변경 사항을 병합하세요.

기능:
- 각 카테고리 내부 상품명/옵션명 검색, 최대 100자
- 추천순: 결제 완료 주문의 판매 수량 기준, 동률 최신 ID
- 최신 등록순 / 낮은 가격순 / 높은 가격순 / 이름 가나다순 / 역순
- 가격 정렬은 상품 기본가와 옵션 가격 중 양수 최저가 기준(가격 없는 상품은 뒤)
- 검색어 및 정렬 상태 유지
- 비회원 상품 가격 숨김

검증: Python 문법 컴파일 및 Jinja 템플릿 구문 검사 통과.
미검증: 실제 PostgreSQL 연결 및 배포 후 UI 동작.
